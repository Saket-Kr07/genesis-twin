# User journeys

## Ananya (Public)
1. Lands on the landing page, sees the avatar and the disclaimer
2. Opens the explorer, rotates the body, switches male/female
3. Moves sleep, exercise and smoking sliders, watches organ colours
4. Clicks an organ, reads vitals and explanation
5. Sees a locked Pro feature, reads the pricing page (decides to stay free)

*Pain points to watch:* finding the layer toggles, understanding colours, locked features.

5. Saves the experiment, exports PDF report
